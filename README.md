# TerraFilter by Flowstate

Marketing website for TerraFilter, a modular water treatment cell based on horizontal levee technology.

The site is a single static page (`index.html`) with five tabs: Home, How it works, Why act now, Pricing, and Contact. Images live in `img/`. There is no build step.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository on GitHub, go to Settings → Pages, choose "Deploy from a branch", and select the `main` branch and the `/ (root)` folder.
